### D-005 go/no-go：建议 go（继续半流程），杀停条件已记录

- 日期：2026-10-25
- 背景：流程 7.7 要求在进入 PRD 前给出继续/停止判断。
- 决策：建议 **go**——技术栈仍在线（小程序 + 云开发）、用户已在实际使用、缺陷可通过最小改动修复，无需重写。
- 理由：现有主链路完整；问题集中在权限、导入语义、选项与视觉，均可在不改数据模型前提下修复。
- 杀停/转向条件（触发则停下向用户报告）：
  1. 用户要求多团队/排班规则引擎/工时结算 → 数据模型需重做，应改走全流程；
  2. 云开发环境无法恢复或视觉 API 停服且无替代；
  3. 线上数据已严重损坏（如大量重复成员/错月排班）且无法安全修复 → 先止损再谈功能。
- 影响：待用户随 UI 决策一并确认；确认前不进入阶段 5 的范围定稿。
