### D-006 排班修改权限：成员仅本人，管理员全量

- 日期：2026-10-25
- 背景：现状 `updateShift`/`importShift` 后端零成员级校验，任何登录成员可改任意人排班；前端仅隐藏入口。
- 决策：用户选择 **A——成员只能改自己，管理员可改所有人**。
- 理由：与《初始设计稿.md》第七节的最初设计一致；后端加校验即可，前端调用参数不变，对旧版小程序兼容友好；比“临时授权”改动小。
- 影响：
  - 阶段 7 必须修改 `cloudfunctions/updateShift/index.js` 与 `cloudfunctions/importShift/index.js`，越权返回 `{ok:false,msg}`；
  - 管理员判定复用白名单/`users.role`，需与 `manageMember.checkAdmin` 统一；
  - 需要新增越权回归用例（成员 A 改成员 B 必须失败）；
  - 导入流程中“非管理员选他人”的 UI 路径必须一并收紧（Q-002 确认后实施）。

### D-007 导入权限：成员仅本人，管理员可任意成员/整表

- 日期：2026-10-25
- 背景：现状 `importShift` 的 commit 无权限校验，前端多人识别时允许非管理员选择他人；整表导入（“全部”）在 UI 中不存在。
- 决策：用户选择 **A**——普通成员只能导入自己（上传整表时自动只保留自己那一行）；管理员可导入任意成员，并可“导入整表（全部）”。
- 理由：与 D-006 的权限模型一致；同时把“一次识别、多人入库”做成管理员能力，避免每人重复调用一次视觉 API 的费用。
- 影响：
  - `importShift` 识别阶段可传 `targetName`（成员导入时锁定该成员，省 token），commit 阶段必须校验“目标成员是否本人或管理员”；
  - 前端 `pages/import`：非管理员隐藏成员选择器；管理员增加“全部”选项；
  - `pages/login` 的导入流程同步收紧（避免两套流程行为不一致）；
  - 需要新增越权导入用例（成员导入他人必须失败）。

### D-011 日历批量/成员名字改用浅蓝强调（用户指定，T-018 返工）

- 日期：2026-10-25
- 背景：用户在实际使用中提出：“批量要移动到与 31 号对齐，批量的背景色与成员名字的背景色都用浅蓝色”；随后按截图进一步要求批量放进最后一排、成员名去边框。
- 决策：
  1. “批量/完成”作为日历最后一排的一个格子，放在当月最后一天右侧的空格（如 10 月 31 日右侧的“日”格）；若最后一天是周日，则紧随其后落到下一排第一格；
  2. 批量文字与同排日期数字同基线；整个日期格可点（104rpx），视觉按钮 56rpx；
  3. 批量、成员横滑标签、非管理员“当前成员”区域使用浅蓝底（`#EFF6FF`），成员名**不加边框**；
  4. 批量选中态用深蓝底白字（`#1D4ED8`）；成员选中态用更深浅蓝（`#DBEAFE`）；
  5. 日历不展示管理员记录；其他元素位置与全局深青绿主色不变。
- 理由：用户明确要求；浅蓝组合实测对比度 6.70–8.49:1，满足可读性。
- 影响：`utils/calendar.js` 新增 `withBatchCell`；日历组件新增批量格与 `batch` 事件；`pages/calendar` 改为基于基础网格重绘；无数据变更。

### D-012 隐藏管理员伪成员并禁止绑定管理员记录

- 影响：管理员记录仍保留在库中用于身份判定；成员列表数量减少；无需数据迁移。

### D-014 排班状态改为 4/6 两套，管理员固定 4 状态

- 日期：2026-10-25
- 背景：用户要求“管理员排班状态只有 4 个”“成员没有特殊排班就默认 4 个，有特殊再扩展”“增加 4/6 状态切换按钮”。
- 决策：
  1. 4 状态 = `休 / 白班 / 晚班 / 年假`；6 状态 = `休 / 正A / 正B / 售A / 售B / 年假`；两者都额外提供“取消”清空动作；
  2. 管理员自己的日历固定 4 状态，不显示 4/6 切换，也不显示“删除成员”；
  3. 成员默认 4 状态；若该成员当月出现任何非基础班次（正/售后/A/B/正A/正B/售A/售B），自动切 6 状态，并把该班次追加进 6 状态选项；
  4. 手动排班弹窗顶部提供“4 状态 / 6 状态”切换；4 状态严格只显示 4 项，6 状态可含该成员已用班次；
  5. 弹窗底部关闭按钮改名“关闭”，与“取消班次”区分。
- 理由：兼顾普通成员的简单排班与细分班次的兼容；管理员只做基础 4 状态，减少误选。
- 影响：`人工必填参数清单.json` 新增两组；`utils/shift.js` 新增 `BASIC_SHIFTS/SPECIAL_SHIFTS/detectShiftMode`；日历弹窗与图例逻辑调整；无数据迁移。

### D-018 空月日历显示“导入”按钮

- 日期：2026-10-28
- 背景：用户希望当前成员某月没有排班时，可以直接从日历进入导入，而不是先切到导入页。
- 决策：
