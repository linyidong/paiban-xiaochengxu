# 操作手册（日历排班小程序）

> 面向接手者/管理员：从零跑起来、日常怎么用、怎么发版、出问题怎么查。
> 本手册不包含真实密钥；参数统一放 `人工必填参数清单.json`（本地，不入库）。

## 0. 前置条件

| 项 | 要求 |
|---|---|
| 微信开发者工具 | 已安装并登录；项目根目录可直接导入 |
| 云开发 | 已开通环境；记录环境 ID |
| Node.js | 18+（本地跑 `node --test`） |
| Python | 3.x（运行 `sync-config.py`；也可双击《同步参数.bat》） |
| 管理员 OPENID | 用于 `ADMIN_OPENIDS` 白名单 |

## 1. 第一次配置（10 分钟）

1. 复制模板：
   ```text
   人工必填参数清单.example.json  →  人工必填参数清单.json
   ```
2. 打开 `人工必填参数清单.json`，填写：
   - `云环境ID`
   - `管理员openid白名单`（数组）
   - `AI识别API_KEY`、`AI识别端点`、`AI识别模型`、`AI识别备用模型`（可空）
   - `成员别名映射`（正式名 → 昵称数组）
3. 同步参数：
   ```powershell
   python sync-config.py
   ```
   会生成：
   - `miniprogram/config.js`
   - `cloudfunctions/login/config.json`
   - `cloudfunctions/updateShift/config.json`
   - `cloudfunctions/manageMember/config.json`
   - `cloudfunctions/importShift/config.json`
   - `cloudfunctions/manageSettings/config.json`
   - `cloudfunctions/getStats/config.json`
4. 在云开发控制台创建集合：
   `users`、`shifts`、`memos`、`changeLog`（可选）、`settings`、`usageLogs`。
5. 部署 9 个云函数（见第 6 节）。

> 以上 `config.json` 与《人工必填参数清单.json》已在 `.gitignore`，不要提交。

## 2. 在开发者工具里跑起来

1. 打开微信开发者工具 → 导入项目 → 选择项目根目录。
2. 确认 `project.config.json` 的 `miniprogramRoot=miniprogram/`、`cloudfunctionRoot=cloudfunctions/`。
3. 点击「编译」；如果页面模板没更新，关闭项目窗口再打开（只点“刷新模拟器”可能不重新编译 WXML）。
4. 首次进入会到登录页：
   - 管理员：白名单 OPENID 自动识别；
   - 成员：选择/新建成员并绑定微信。

## 3. 管理员初始化

1. 登录后进入「我的」；
2. 打开「成员管理」→ 新增成员，或让成员自己绑定；
3. 打开「设置」：
   - 主模型名称 / 主模型 API Key；
   - 备用模型名称 / 备用模型 API Key（可空，空则复用主 Key）；
   - 保存后立即生效。
4. 打开「技术栈」确认当前模型与版本；
5. 打开「数据」查看成员/排班/使用统计。

## 4. 日常操作

### 4.1 导入排班（截图）

1. 进入「导入」；
2. 选择「导入到哪个月」（可选；不选则按截图月份）；
3. 选择截图 → AI 识别；
4. 在预览里逐项校对班次（点班次可循环切换）；
5. 确认导入：
   - 按「成员 + 月份」整月覆盖；
   - 目标月不存在的日期会丢弃并提示（如 11-31）；
6. 成功后自动回到对应成员/月份。

### 4.2 导入 Excel

同上传入口，选择 `.xlsx`；解析结果与截图预览一致。

### 4.3 手动改班

- 点某天 → 选择班次；
- 长按某天 → 进入多选 → 点选多天 → 批量设置；
- 日历最后一排有「批量」；空月还会出现「导入」；
- 4/6 状态切换：弹窗顶部选「4 状态 / 6 状态」；管理员默认 4 状态，也可切 6。

### 4.4 成员与备忘录

- 成员管理：新增、绑定、解绑、软删除（保留历史排班）；
- 备忘录：按「几月几号 + 事件」格式添加，按年+月分组。

## 6. 部署云函数

在开发者工具「云开发」面板，或右键每个函数目录：

```text
login
getShifts
updateShift
importShift
manageMember
manageMemo
manageSettings
getStats
trackUsage
```

选择「上传并部署：云端安装依赖」。部署后确认状态 Active；`importShift` 超时设为 **60s**（识别可能 10–36s）。

> 新增函数首次部署可能遇到 `Creating` 状态导致 `UpdateFunctionCode` 失败；等函数 Active 后重试一次。

## 7. 上传体验版 / 发布

1. 开发者工具「上传」；
2. 填写版本号与备注；
3. 到微信公众平台 → 管理 → 版本管理：
   - 开发版本「选为体验版」；
   - 验证后「提交审核」→ 发布。

## 8. 故障排查

| 现象 | 排查 |
|---|---|
| 页面白屏/模板旧 | 关闭项目窗口重开，或点「编译」；只刷新模拟器不够 |
| 双击后只有深灰空白窗口 | 用 `--disable-gpu` 启动（桌面/开始菜单快捷方式已加该参数） |
| 启动后秒退（ExitCode 0/9） | 先清掉环境变量 `ELECTRON_RUN_AS_NODE`，再启动 `微信开发者工具.exe` |
| 登录面板“网络连接失败”/未登录 | 运行 `cli.bat login --lang zh` 重新扫码；检查系统时间、代理与 `open.weixin.qq.com` 连通性 |
| 导入报“识别服务未配置” | 检查 `importShift/config.json` 的 Key/端点/模型；设置页是否保存了空 Key |
| 导入报“主/备模型均识别失败” | Key 是否失效、模型名是否存在；看云函数日志 |
| 识别月份不对 | 导入页先选目标月份；预览会按目标月重写 |\n| 导入后出现 50 多天 | 已在客户端和 `importShift` 双重按目标月天数截断；仍异常时检查预览日期是否跨月 |
| 改班无效 | 是否改的别人排班（成员只能改自己）；看云函数返回 `ok:false` 原因 |
| 成员列表看不到管理员 | 设计如此：管理员记录被隐藏，避免被绑定提权 |
| 数据页统计为 0 | `usageLogs` 是否创建、`trackUsage` 是否部署；统计从接入后开始 |
| `settings` 保存失败 | 集合是否创建；Key 是否至少 8 位且无空格 |

## 9. 安全与回滚

- 不要提交 `cloudfunctions/*/config.json`、`project.private.config.json`、`人工必填参数清单.json`；
- 设置页会显示 API Key，仅管理员可见；不要截图外发；
- Key 泄露：立即到火山方舟重置，再在设置页保存新 Key；
- 回滚云函数：从上一版代码重新部署；
- 回滚客户端：公众平台版本管理回退上一线上版本；
- 数据：无迁移脚本；测试写入按测试成员/日期定向清理。
