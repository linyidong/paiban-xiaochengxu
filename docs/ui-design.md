## 1. 原设计盘点（现状）

- 无设计稿文件、无 Figma/即时设计链接、无设计系统文档、无品牌素材（logo/字体/色板）文件。

### 1.4 风格一致性

- **整体一致**：全部页面共用 `.card`、`.btn-primary`、`.btn-ghost` 与同一色板；无第二套按钮/卡片。
- **三类不一致**：
  1. 颜色双源：`config.js` 的 `STYLE` 与 WXSS 硬编码并存，改配置不会改变样式；
  2. 班次颜色两套：`SHIFT_COLOR`（config）与 `DEFAULT_SHIFT_COLORS`（`calendar.js:6`）各自维护；
  3. 页签/空态：日历用灰圆占位图标（`calendar.wxss:134-137`），其他页无统一空态样式。

### 1.6 样式实现方式

- 全局 `app.wxss` + 每页独立 `.wxss`；WXML 内联 `style` 仅用于动态班次颜色（`calendar.wxml:9,50,65`）。
- 无 CSS Modules / Tailwind / 组件库 / 设计 token 文件。
- 组件仅 1 个（`components/calendar`），无 UI 组件库。

## 2. 设计基准（B 分支）

### 2.1 PRODUCT.md

| 项 | 内容 |

## 6. 反模式黑名单（目标，0 违例）

- 禁止渐变、glassmorphism、暗色辉光、bounce/elastic 缓动。
- 禁止纯黑/纯灰背景；禁止彩色底配低对比灰字。
- 禁止 emoji 当图标、三列图标卡、无意义分隔细线。
- 禁止仅用颜色区分班次：每个班次块必须带中文/字母文本。
- 正文 ≥16px；触控 ≥88rpx；对比度 ≥4.5:1；焦点态可见。

## 8. 视觉验收判据

### 8.1 现状基线（2026-10-25 测量）

| # | 判据 | 现状/测量 | 结果 |
|---|---|---|---|
| 1 | 正文 ≥16px | 8 个 WXSS 共 121 处 `font-size`，其中 `28rpx`（14px）25 处、`26rpx`（13px）15 处、`24rpx`（12px）12 处 | **不满足**（主体 12–14px） |
| 2 | 对比度 ≥4.5:1（正文） | `#9CA3AF` on `#FFFFFF` = **2.54:1**；`#3B82F6` on `#F7F8FA` = **3.46:1**；`#EF4444` on `#FFFFFF` = **3.76:1**；白字 on `#F3F4F6` = **1.10:1** | **不满足**（多处） |
| 3 | 触控目标 ≥44px | `.month-nav` 仅左右 padding；`.memo-edit`/`.memo-delete` 为纯文字（`memo.wxss`） | 部分不满足 |
| 4 | 黑名单 0 违例 | 无紫蓝渐变/玻璃拟态/emoji 图标；但有彩色底配白字（班次标签，红/蓝对比 3.7:1） | 1 类边缘违例 |
| 5 | 与原设计基准一致（A 分支） | 缺截图基准 | **未执行**（Q-010） |
| 6 | 无横向滚动/溢出 | `.legend-row` 为 `space-between` 且不换行，11 种班次时可能溢出 | 待真机验证 |

### 8.2 目标验收判据（B 分支，全部 PASS 才算通过）

| # | 判据 | 可数测量方式 |
|---|---|---|
| 1 | 正文 ≥16px | 全 WXSS 检索 `font-size`，正文类不得出现 <`32rpx`（辅助信息 `28rpx` 需列白名单） |
| 2 | 文字对比度 ≥4.5:1 | 脚本按 WCAG 计算所有“文字色/背景色”组合，0 组低于 4.5 |
| 3 | 班次块白字对比 ≥4.5:1 | 8 个班次色与白字组合全部 ≥4.5（当前目标色盘最低 4.83） |
| 4 | 触控目标 ≥88rpx | 所有可点击元素计算高度/宽度，0 个低于 88rpx |
| 5 | 无横向滚动/裁切 | 390×844 与 768×1024 截图，`scrollWidth == clientWidth` |
| 6 | 旧色值清零 | 全 WXSS 检索旧值（`#3B82F6`/`#9CA3AF`/`#F7F8FA` 等）出现次数 = 0 |
| 7 | 黑名单 0 违例 | 对照第 6 节逐条截图自查 |
| 8 | 班次可辨识 | 每个班次块同时有颜色 + 文本；黑白模式截图仍可区分 |
| 9 | 空态/错误态齐全 | 日历无数据、无备忘录、导入失败、网络失败 4 种状态均有截图 |
