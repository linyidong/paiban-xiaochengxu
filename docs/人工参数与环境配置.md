# 人工参数与环境配置

> 阶段 3 产出。**只写变量名、用途、示例值；绝不写真实密钥、密码、证书内容。**
> 真实值保存在本机《人工必填参数清单.json》与云函数 `config.json`，分发脚本见 `sync-config.py`。

## 1. 原则

- 人工必填参数集中在根目录《人工必填参数清单.json》（唯一权威来源），由 `同步参数.bat` 分发到代码。
- `miniprogram/config.js` 与各云函数 `config.json` **自动生成，禁止手改**。
- 前端配置会随小程序包下发，**不能放秘密**；`MEMBER_ALIAS` 属成员昵称，可接受。
- 云函数 `config.json` 含密钥，已加入 `.gitignore`，仅本机与云端保存。
- 缺失必需参数时，当前代码**并非全部报错**：`importShift` 会静默回退假数据（见 BUG-020），这是需要修的危险默认值。

## 2. 环境清单

| 环境 | 用途 | 地址/入口 | 负责人 |
|---|---|---|---|
| 本地 | 开发/调试 | 微信开发者工具打开项目根目录 | 项目所有者 |
| 生产 | 线上小程序 + 云开发 | 微信公众平台 + 云开发环境 `paiban-<环境后缀>`（完整值见清单） | 项目所有者 |

## 3. 人工必填参数

| 参数名 | 必填 | 类型 | 用途 | 从哪里获取 | 放在哪里 | 是否敏感 | 缺失时的行为 |
|---|---|---|---|---|---|---|---|
| `env` | 是 | string | 云开发环境 ID | 云开发控制台 | `miniprogram/config.js`（生成） | 否 | `wx.cloud.init` 失败，所有云函数调用失败 |
| `ADMIN_OPENIDS` | 是 | string[] | 管理员白名单 | 小程序后台/`login` 返回的 openid | `cloudfunctions/{login,updateShift,manageMember}/config.json` | 是（身份标识） | `require('./config.json')` 抛错，三个云函数不可用 |
| `AI_VISION_API_KEY` | 是 | string | 视觉识别鉴权 | 火山方舟控制台 | `cloudfunctions/importShift/config.json` | **是（密钥）** | 回退 `mockPreview()` 假数据（危险） |
| `AI_VISION_ENDPOINT` | 是 | url | 识别端点 | 服务商文档 | 同上 | 否 | 同上 |
| `AI_VISION_MODEL` | 是 | string | 模型名 | 服务商控制台 | 同上 | 否 | 同上 |
| `MEMBER_ALIAS` | 否 | object | 正式名 → 别名数组 | 项目所有者维护 | `config.js` + `importShift/config.json` | 否（昵称） | 导入时无法把昵称归位到正式名 |
| `SHIFT_TYPES` | 是 | string[] | 班次枚举 | 业务定义 | `miniprogram/config.js` | 否 | 页面回退默认 5 项，导入预览循环受限 |
| `SHIFT_COLOR` | 否 | object | 班次颜色 | 业务定义 | 同上 | 否 | 未配置班次显示灰色 |
| `STYLE`（bg/cardBg/primary/radiusCard/radiusBtn） | 否 | object | 主题样式 | 业务定义 | 同上 | 否 | 页面使用硬编码样式 |

## 4. 配置分层

1. **秘密信息**：`AI_VISION_API_KEY`（仅服务端）。历史上曾写入被 Git 跟踪的《人工必填参数清单.json》，需轮换后移出跟踪。
2. **身份配置**：`ADMIN_OPENIDS`（服务端，勿下发前端）。
3. **业务参数**：`SHIFT_TYPES`/`SHIFT_COLOR`/`MEMBER_ALIAS`/`STYLE`（前端 + 部分服务端）。
4. **运行时数据**：用户排班、备忘录（云数据库）。

## 5. 敏感配置管理

- 存放位置：本机《人工必填参数清单.json》、各云函数 `config.json`、云开发控制台环境变量（当前未使用）。
- 谁能访问：项目所有者 + 获得仓库/云环境权限的人。
- 轮换周期：无既定周期；**发现入库后应立即轮换**。
- 泄露处置流程：① 在服务商控制台作废旧 Key；② 生成新 Key 写入清单并 `同步参数.bat`；③ 重新部署 `importShift`；④ 用 `git rm --cached` 移出跟踪并加入 `.gitignore`；⑤ 历史清理需单独授权（`filter-repo`/BFG）。
- `.env.example`：本项目不使用 `.env`，等价物为《人工必填参数清单.json》；建议提供 `人工必填参数清单.example.json`（只含占位符）。
