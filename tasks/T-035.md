# T-035 设置页支持主/备模型 API Key 在线修改

- 任务编号：T-035（用户 2026-10-28 需求）
- 阶段：7（增补）
- 优先级：P0
- 风险等级：高（密钥）
- 对应需求：F-021
- 前置任务：T-026、T-034
- 状态：已完成（2026-10-28，commit `待填`；部署/上传待确认）

## 1. 目标

1. 删除设置页“查看技术栈”入口；
2. 设置页增加：主模型名称、主模型 API Key、备用模型名称、备用模型 API Key；
3. 填好后点“保存设置”立即生效，无需改配置文件；
4. 首次打开显示当前主模型与主 Key（来自云端配置或已保存设置）。

## 2. 实现

- `manageSettings`：
  - `get` 返回 `primaryApiKey`、`fallbackApiKey`（仅管理员）；
  - `save` 校验并保存到 `settings/ai`；
  - 主 Key 必填；备用 Key 可空，空则复用主 Key；
  - 不把 Key 写入日志/返回错误详情。
- `importShift`：
  - 读取 `settings/ai` 的模型与 Key；
  - 模型候选改为 `{model, apiKey}`；备用 Key 为空时复用主 Key；
  - `Authorization` 使用候选的 Key；
  - 主模型失败仍自动切备用模型。
- 设置页：四个字段；移除技术栈卡片；提示“仅管理员可见、请勿截图”。
- 新增 `tests/t035-settings-keys.test.js`；更新 T-026 用例。

## 4. 风险

- API Key 存在云数据库 `settings/ai`，并下发到管理员设置页；管理员设备/截图可能泄露，需谨慎。
- 未做 Key 加密存储；依赖云数据库权限与管理员边界。
- 修改 Key 后立即影响识别；Key 错误会表现为“主/备模型均识别失败”。
