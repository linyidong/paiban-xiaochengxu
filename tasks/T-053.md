# T-053 腾讯云表格 OCR V3 主识别

- 任务编号：T-053（用户 2026-11-01 指定）
- 状态：代码已完成并部署 `importShift`；等待配置腾讯云 SecretId/SecretKey 后用真图验收

## 目标

- 排班截图优先走腾讯云 `RecognizeTableAccurateOCR`（表格识别 V3）；
- 用单元格行列坐标还原表格，避免视觉大模型漏行；
- OCR 未配置/失败时回退现有 DeepSeek 视觉识别；
- Excel 解析保持不变。

## 实现

- `cloudfunctions/importShift/index.js`
  - 新增 `recognizeTableByTencent()`：调用 `RecognizeTableAccurateOCR`，`UseNewModel: true`；
  - 新增 `parseTencentTable()`：按 `RowTl/ColTl` 还原表头、昵称/人员列、日期列；
  - `recognizeImage()` 先尝试腾讯 OCR，空结果再走原视觉模型；
- `cloudfunctions/importShift/package.json`
  - 新增依赖 `tencentcloud-sdk-nodejs-ocr`（`^4.0.0`）；
- 凭证只从云函数环境变量读取：
  - `TENCENT_SECRET_ID`
  - `TENCENT_SECRET_KEY`
  - `TENCENT_OCR_REGION`（可选，默认 `ap-guangzhou`）
  - `TENCENT_OCR_ENABLED`（可选，`0` 关闭）
