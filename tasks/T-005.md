# T-005 导入后定位 + 完整班次/取消

- 任务编号：T-005
- 阶段：7
- 优先级：P0
- 风险等级：中
- 对应需求：F-005、F-006
- 前置任务：T-001、T-004
- 状态：进行中

## 1. 目标

1. 导入成功后，日历自动切换到“被导入成员 + 对应年月”，而不是回到当前月；
2. 班次选项统一为 `config.SHIFT_TYPES`（11 种）+ `取消`，图例同源；
3. 导入预览的循环切换也包含“取消”，取消表示该日清空（由 T-004 的全量替换落地）。

## 2. 修改范围

**允许修改：**
- `miniprogram/utils/shift.js`（新增 `CANCEL`/`getShiftOptions`）
- `miniprogram/pages/calendar/calendar.js`（onShow 定位、班次选项/图例）
- `miniprogram/pages/import/import.js`（写入 `importTarget` 年月、预览循环含取消、commit 不再传当前年月）
- `miniprogram/pages/login/login.js`（同上：importTarget、循环含取消、不传当前年月）
- `cloudfunctions/importShift/index.js`（commit 过滤“取消”）
- `tests/t005-shift-options.test.js`

**明确禁止：**
- 不改页面路由、不改 `shifts` 结构
- 不移除批量改班
- 不手改 `config.js`
- 不改视觉样式（留 T-013～T-015）

## 3. 验收标准（可数）

- [ ] `getShiftOptions()` 返回 12 项（11 班次 + 取消），且不含“白班/晚班”
- [ ] 普通成员与管理员看到的选项/图例一致（都来自 `config.SHIFT_TYPES`）
- [ ] 导入成功后 `importTarget = {name, year, month}`，日历 onShow 使用该年月与成员
- [ ] 点击“取消”后该日 `shifts` 记录数 0，且不写入 `shiftType='取消'`
- [ ] 预览全部标记取消 → 该月旧记录清空
- [ ] 部分取消 + 部分班次 → 取消日删除、班次日更新
