# T-001 设计 token 与班次色盘落地

- 任务编号：T-001
- 阶段：7
- 优先级：P0
- 风险等级：低
- 对应需求：F-012（视觉换新）
- 前置任务：无
- 状态：进行中

## 1. 目标

建立唯一视觉令牌层（CSS 变量）与全新班次色盘，为 T-013～T-015 的页面迁移提供基础；不改页面结构与交互。

## 2. 修改范围

**允许修改：**
- `人工必填参数清单.json`：`前端参数.班次颜色`、`前端参数.界面样式`（只改这两块，不动密钥/白名单/别名）
- 运行 `同步参数.bat`（即 `python sync-config.py`）生成：
  - `miniprogram/config.js`
  - `cloudfunctions/{login,updateShift,manageMember}/config.json`
  - `cloudfunctions/importShift/config.json`
- `miniprogram/app.wxss`：新增 CSS 变量，并让 `page/.card/.btn-primary/.btn-ghost` 使用变量

**明确禁止：**
- 不手改生成文件（除脚本生成外）
- 不改页面 `*.wxss`（留给 T-013～T-015）
- 不改 WXML/JS 结构、不改路由
- 不改密钥、openid、别名映射
- 不删除 `白班/晚班/取消` 兼容色（旧数据仍可能引用）

## 3. 验收标准（可数）

- [ ] `人工必填参数清单.json` 可被 `JSON.parse` 解析
- [ ] `miniprogram/config.js` 的 `SHIFT_COLOR` 与目标色盘逐项相等（14 个键）
- [ ] 8 个班次色 + 白字对比度全部 ≥4.5:1（脚本输出）
- [ ] `app.wxss` 含 `--color-primary: #0F766E` 等 ≥10 个变量
- [ ] `app.wxss` 中旧主色 `#3B82F6` 出现次数 = 0
- [ ] `config.js` 的 `env`、`MEMBER_ALIAS` 与改动前一致（未误伤）
- [ ] 云函数 4 个 `config.json` 仍为合法 JSON，且 `ADMIN_OPENIDS`/AI 字段存在（不打印值）

## 4. 测试要求

- JS 脚本：JSON 解析 + 色盘逐项比对 + WCAG 对比度计算
- 静态检查：旧色值计数、变量计数
- 人工验收：开发者工具编译（若已登录），日历班次色变深且文字清晰；未登录则标“未执行”
- 回归：登录/日历/导入页面能正常加载（编译级）
