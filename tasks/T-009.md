# T-009 管理员整表导入（全部）

- 任务编号：T-009
- 阶段：7
- 优先级：P1
- 风险等级：中
- 对应需求：F-011
- 前置任务：T-004、T-005
- 状态：进行中

## 1. 目标

管理员识别到多人时，可一键“全部导入”，一次 commit 写入整表（每位成员各自按月全量替换）；普通成员没有该入口，后端权限已由 T-004 保证。

## 2. 修改范围

**允许修改：**
- `miniprogram/pages/import/import.js`、`import.wxml`、`import.wxss`
- 新增 `tests/t009-import-all.test.js`（后端多人提交回归）

**明确禁止：**
- 不向普通成员开放“全部”
- 不改单人导入路径
- 不改 `preview` 结构
- 不改视觉 token

## 3. 验收标准（可数）

- [ ] 管理员多人识别后，面板出现“全部导入（N 人）”
- [ ] 点击后 `preview` 为完整列表、`targetName='全部'`、面板关闭
- [ ] 确认后一次 commit 写入 N 人，每人按自己月份全量替换
- [ ] 普通成员看不到该入口（识别已锁定本人）
- [ ] 导入后日历定位到第一位被导入成员与月份

## 4. 测试要求

- `node --test tests/t009-import-all.test.js` 通过（≥2 条）
- 全量回归 `node --test`（≥52 条）
- 人工验收（待登录 + 测试成员）：识别 3 人表 → 全部导入 → 3 人日历均更新
