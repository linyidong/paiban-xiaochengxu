## 1. 目标

`updateShift` 在写入前校验“调用者是目标成员本人或管理员”；拒绝非法日期；`updatedBy` 统一写 `users._id`；保持入参不变以兼容旧版小程序。

## 2. 修改范围

**允许修改：**
- `cloudfunctions/updateShift/index.js`
- 新增 `tests/` 下的 mock 与用例（T-016 会继续扩展）

**明确禁止：**
- 不改云函数名与入参（`name/shift/dates/date`）
- 不删除“`shift` 为空 = 取消并删除记录”的语义
- 不改 `shifts`/`changeLog` 字段结构
- 不动其他云函数与前端

## 3. 验收标准（可数）

- [ ] 成员改自己 → `ok:true`，记录 `updatedBy === me._id`
- [ ] 成员改他人 → `ok:false`，目标数据 0 变化
- [ ] 管理员改他人 → `ok:true`
- [ ] `2026-02-30` → `ok:false`，写入 0 条
- [ ] `2024-02-29`（闰年）→ `ok:true`

- [ ] 同名多成员（>1）→ `ok:false`，不猜测目标
- [ ] 原有 `changeLog` 仍写入
