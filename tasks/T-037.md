# T-037 修复批量按钮遮挡 29 号

- 任务编号：T-037（用户 2026-10-30 截图反馈）
- 阶段：7（增补）
- 优先级：P1
- 状态：已完成，1.3.7 已上传；待体验版验证

## 1. 现象

成员端 2026-11 日历：
- 第 5 行 23–28 后直接是“批量”，**29 号消失**；
- 批量按钮下方露出半截蓝色班次标签（29 号的班次被遮住）；
- 空月时“导入”入口也可能不出现/位置异常。

## 2. 根因

- `withBatchCell` 把“批量/导入”伪造成日期格（`isBatch/isImport`）注入 `cells`；
- 注入的伪格 `fullDate` 为空，和 `wx:key="fullDate"` 的键冲突；
- 一旦目标位置落在已有日期上，就会覆盖该日期（本次是 29 号）。

## 3. 修复

- 日历组件只渲染真实日期格；
- “批量/导入”移到网格外的 `.cal-actions` 操作条；
- 组件新增 `batchLabel/batchOn/showImport` props，事件仍为 `batch/import`；
- 页面不再调用 `withBatchCell`，改为把状态传给组件；
- 新增 `tests/t037-batch-action-bar.test.js`，断言 2026-11 的 29/30 不被移除、页面不再注入伪日期格。

## 4. 验收

- [x] 2026-11 网格含 29/30；

- [x] 操作条在网格下方，不覆盖日期；
- [x] `node --test` 143/143；
