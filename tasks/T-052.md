# T-052 命中确认、候选选择、持久绑定与同名注册去重

- 任务编号：T-052（用户 2026-11-01 流程定义）
- 状态：已完成，1.7.0 已上传；`manageMember` 已部署

## 目标流程

1. 成员昵称导入 → 先查排班表是否有该昵称/真实姓名；
2. 命中 → 列出对应昵称/真实姓名，询问“是否是排班表里的这个人”；
3. 用户确认 → 持久绑定真实姓名并导入；
4. 未命中 → 列出表里未绑定人员，让用户选一位 → 持久绑定并导入；
5. 新建同名成员 → 先问“是不是已有的菓菓/吴义芳”；不是则必须换新昵称+新真实姓名。

## 实现

- `manageMember.checkName`：查同名成员的昵称/真实姓名/绑定状态；
- `manageMember.setRealName`：成员只能设自己，管理员可设任意；导入映射时自动调用并持久化；
- 导入命中：弹“确认成员对应关系”；取消 → `_showCandidatesForTarget` 列未绑定候选；
- 未命中：列候选，选中后 `_applyMappedRow` 持久绑定；
- 登录创建：先 `checkName`；已有同名成员时弹“是我/不是我”；
  - 是我 → 已绑定他人则提示联系管理员；未绑定则绑定；
  - 不是我 → `forceNewIdentity`，必须换新昵称并填写新真实姓名。
- 新增创建表单“真实姓名”字段。
