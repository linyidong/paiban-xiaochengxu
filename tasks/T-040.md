# T-040 绑定唯一性与管理员/成员同步

- 任务编号：T-040（用户 2026-10-30 需求）
- 状态：已完成，1.3.9 已上传；`manageMember` 已部署

## 目标

1. 管理员导入后，未绑定成员在登录页可选；已绑定成员隐藏，管理员解绑后才重新出现；
2. 未选择/未绑定时可自己创建成员；
3. 绑定后成员唯一；管理员和成员操作同一条 `users` 记录时，排班双向同步。

## 实现

- `manageMember.list` 支持 `bindable:true`：只返回未绑定成员，以及当前用户自己的记录；
- 登录页 `loadMemberList` 传 `bindable:true`，已绑定他人不再显示；
- `bindWechat` 改为条件更新 `where({_id, openid:''})`，并发抢绑只有一个成功；
- 排班按 `users._id` 关联：管理员导入自动建档（openid 空）→ 成员登录选该名字绑定 → 同一 userId 下改班，管理员刷新即可看到；
- 管理员端 `onShow`/切月重新拉取，保证同步。
