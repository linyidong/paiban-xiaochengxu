# T-012 隐私最小化（openid）

- 任务编号：T-012
- 阶段：7
- 优先级：P2
- 风险等级：低
- 对应需求：F-015
- 前置任务：T-003
- 状态：进行中

## 1. 目标

`manageMember.list` 不再向普通成员返回他人 openid：管理员可见 openid，普通成员只拿到 `isBound` / `isSelf` 布尔；成员管理页不再展示 openid；登录页改用布尔判断“自己/未绑定”。

## 2. 修改范围

**允许修改：**
- `cloudfunctions/manageMember/index.js`（仅 list）
- `miniprogram/pages/members/members.wxml`
- `miniprogram/pages/login/login.js`（loadMemberList）
- 新增 `tests/t012-privacy.test.js`

**明确禁止：**
- 不改登录/绑定流程的结果
- 不删除管理员查看 openid 的能力
- 不改其他接口字段
- 不迁移数据

## 3. 验收标准（可数）

- [ ] 管理员 `list` 返回 `openid` 字段
- [ ] 普通成员 `list` 返回**不含** `openid` 字段
- [ ] 两条路径都返回 `isBound`、`isSelf`
- [ ] 自己的记录 `isSelf=true`，他人 `false`
- [ ] 登录页仍能区分“已绑定自己”和“未绑定可认领”
- [ ] 成员页不展示 openid，绑定状态用 `isBound`

## 4. 测试要求

- `node --test tests/t012-privacy.test.js` 通过（≥4 条）
- 全量回归 `node --test`（≥65 条）
- 人工验收（待登录）：普通成员打开成员页看不到 openid
