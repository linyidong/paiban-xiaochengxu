## 1. 目标

在成员管理页恢复“新增成员”入口：管理员输入姓名即可创建未绑定成员；非管理员看不到、后端也拒绝；同名（含已软删除）给出明确错误。

## 2. 修改范围

**允许修改：**
- `miniprogram/pages/members/members.js`、`members.wxml`、`members.wxss`
- 新增 `tests/t007-add-member.test.js`

**明确禁止：**
- 不改 `manageMember.add` 入参
- 不开放给非管理员
- 不改成员列表排序/字段
- 不改视觉 token（新增样式使用已有 CSS 变量）

## 3. 验收标准（可数）

- [ ] 管理员新增“张三” → `users` +1，列表出现“张三/未绑定”
- [ ] 非管理员调用 `add` → `ok:false`（仅管理员）
- [ ] 新增已存在姓名 → `ok:false`
- [ ] 新增已软删除姓名 → `ok:false` 且提示“可能已删除”
- [ ] 新增成功后表单清空、列表刷新
- [ ] 空姓名 → 前端拦截，不发请求
