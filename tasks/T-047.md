# T-047 导入入口区分

- 任务编号：T-047（用户 2026-11-01 需求）
- 状态：已完成，1.5.2 已上传

## 目标

- 从成员日历点“导入” → 显示“目标：东子 · 2026-11”和已选月份；
- 直接点底部“导入” → 不显示目标，显示“按截图识别的月份（默认）”。

## 实现

- 导入页新增 `onTabItemTap`：用户直接点底部 tab 时清空 `prefillName/targetName/targetMonth/preview`；
- `onShow` 读取 `importPrefill`：
  - 有 prefill → 设置目标成员和月份；
  - 首次进入或刚点底部 tab → `_clearEntry()`，显示默认入口；
- 图片选择/聊天选择返回时不会误清空，因为只有 tab 点击/首次进入才重置。
