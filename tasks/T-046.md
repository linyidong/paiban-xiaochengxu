# T-046 成员昵称 + 真实姓名双重匹配

- 任务编号：T-046（用户 2026-11-01 需求）
- 状态：已完成，1.5.0 已上传；`manageMember`/`importShift` 已部署

## 目标

- 成员同时有“昵称”和“真实姓名”；
- 导入先按昵称、再按真实姓名匹配；
- 已绑定的昵称/真实姓名不再作为其他人的候选；
- 管理员成员管理显示并可修改“昵称 → 真实姓名”。

## 实现

- `users.realName` 可选字段；`manageMember.list` 返回，`rename`（管理员）可同时改昵称/真实姓名；
- 成员管理页显示“真实姓名：xxx / 未绑定真实姓名”，编辑时两个输入框；
- Excel 解析按表头识别 `昵称`/`人员|姓名` 列，不再把“分组”当人名；
- AI 识别 prompt 要求分别输出 `nickname`/`realName`；
- 导入页加载成员目录：
  - 昵称命中或真实姓名命中 → 直接采用该行，不再弹确认；
  - 都不命中 → 列出**未被其他微信绑定**的候选，用户选一行映射到目标成员；
  - 候选全被绑定 → 拒绝，不重复绑定；
- 提交仍带 `targetName`，服务端二次锁定。
