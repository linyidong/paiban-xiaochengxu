## 1. 目标

1. 管理员“我的”页增加 **设置** 与 **技术栈** 入口；
2. 把已配置的 AI 模型移到 **设置** 页，可在小程序内直接改；
3. 设置页支持 **主模型 + 备用模型**，一步保存；
4. 识别时主模型失败自动尝试备用模型；
5. 技术栈页展示当前技术栈与模型配置，可跳转设置。

## 2. 实现

- 新增云函数 `manageSettings`：管理员 `get/save`，设置存 `settings/ai`；只存模型名，API Key/端点仍在云端 config；
- 新增页面 `pages/settings`、`pages/techstack`，仅管理员可访问；
- “我的”页管理员卡片加入设置/技术栈入口；
- `importShift` 读取 `settings/ai`，主模型失败自动换备用模型；
- 参数表新增 `AI识别备用模型`，同步到云函数 config。

## 4. 风险

- 设置只存模型名；API Key 修改仍需云端 config，避免密钥下发客户端。
- 备用模型只在 API 报错时切换；主模型返回不可解析 JSON 时不会自动切换（后续可扩展）。
- 模型名格式限制 `[A-Za-z0-9._:-]{1,100}`。
